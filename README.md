A modern, lightweight Project Management Application built using pure HTML, CSS, and JavaScript. It helps teams manage projects, tasks, and members with an intuitive dashboard and Kanban interface.

🚀 Features
🔐 Authentication
User login & signup system
Role-based access:
Admin
Member
📁 Project Management
Create, view, and delete projects
Assign team members to projects
Track project progress visually
✅ Task Management
Create and assign tasks
Set:
Priority (High / Medium / Low)
Status (To Do / In Progress / Done)
Due dates
Mark tasks complete
Delete tasks
📊 Dashboard
Overview of:
Total projects
Total tasks
Completed tasks
Overdue tasks
Quick view of upcoming tasks
📌 Kanban Board
Drag-style workflow visualization:
To Do → In Progress → Done
Easily update task status
👥 Team Management (Admin Only)
View all team members
Change user roles (Admin / Member)
Track user activity (projects & tasks)
🛠️ Tech Stack
Frontend: HTML5, CSS3, JavaScript (Vanilla)
Storage: Browser localStorage
UI Design: Custom CSS (Dark theme)
